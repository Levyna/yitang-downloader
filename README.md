# 一堂课程下载追踪系统

> 自动追踪一堂课程下载任务的系统

## 功能

- 接收课程链接（回放、文稿、作业）
- 记录到飞书 Base 表格
- 自动执行下载
- 标记完成状态

## 表格字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 课程名称 | 文本 | 课程标题 |
| 课程日期 | 日期 | 直播日期 |
| 回放链接 | URL | air.yitang.top/live/* |
| 文稿链接 | URL | yitang.top/fs-doc/* |
| 作业链接 | URL | yitang.top/homework/* |
| 状态 | 单选 | 待处理/进行中/已完成/失败 |
| 创建时间 | 创建时间 | 自动记录 |
| 完成时间 | 修改时间 | 完成时记录 |
| 本地路径 | 文本 | 下载后的本地目录 |
| 备注 | 文本 | 失败原因等 |

## 工作流程

```
用户发送链接
  ↓
解析链接 + 记录到 Base（状态=待处理）
  ↓
执行下载（状态→进行中）
  ↓
完成（状态→已完成） 或 失败（状态→失败 + 原因）
```

## 使用

```bash
# 发送链接给 CC
# 格式：
回放：https://air.yitang.top/live/...
文稿：https://yitang.top/fs-doc/...
作业：https://yitang.top/homework/...（可选）
```

## 依赖

- Chrome DevTools MCP（浏览器控制）
- 飞书 CLI（Base 表格操作）
- ffmpeg（音视频处理）
