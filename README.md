# 一堂课程下载追踪系统

> 自动追踪一堂课程下载任务的系统

## 文件结构
```
P003-YITANG-Downloader/
├── 下载追踪表.xlsx     # 主追踪表（16列）
├── CLAUDE.md           # 项目配置
└── README.md           # 本文件
```

## 追踪表字段（16 列）

| 序号 | 日期 | 分类 | 来源 | 内容名称 | 回放链接 | 文稿链接 | 其他链接 | 视频下载 | 音频提取 | 文稿下载 | 音频转录 | 整体状态 | 文件路径 | 失败原因 | 备注 |
|------|------|------|------|----------|----------|----------|----------|----------|----------|----------|----------|----------|----------|----------|------|

**状态选项**：
- 待处理
- 进行中
- 已完成
- 失败

**分类选项**：
- 一堂会员日
- 水水AI前哨
- 读书会
- 其他

## 工作流程

```
用户发送链接
  ↓
解析并填入 Excel 表（状态=待处理）
  ↓
执行下载（状态→进行中）
  ↓
完成（状态→已完成 + 文件路径）
或失败（状态→失败 + 失败原因）
```

## 使用

发送链接给 CC，格式：
```
回放：https://air.yitang.top/live/...
文稿：https://yitang.top/fs-doc/...
作业：https://yitang.top/homework/...（可选）
```

## 技能

调用 `/yitang-download` 执行下载。
